Критерии: реальные списания эссенции/предметов; аварии изменяют мир по исходным правилам; стабилизатор тратит настоящий заряд; рецепт сохраняет полную идентичность; многопредметный/компонентный результат и контейнер переживают NBT; чужая квитанция не разрешает ACK. Полный M06 не объявляется завершённым при открытых зависимостях и непроверенной Survival-прогрессии.

## 05.11.2026 — питание матрицы через реальные зеркала

Следующий подтверждённый пробел M06: существующий matrix source bridge видит только банки. BETA26 `TileMirrorEssentia.takeFromContainer` использует реальную связанную пару, направление удалённого зеркала, `range=8`, `ignoreMirror=true`, `fxDelay=5`; после успешного списания вызывает `addInstability(null,1)` только на вызывающем зеркале. Это отдельный беспроводной путь IAspectSource, не существующий трубный IEssentiaTransport.

Решение: общий M06 scanner сохраняет приоритет расстояния и 10-секундную задержку повторного поиска, допускает зеркала у матрицы; новый узкий метод зеркала вызывает тот же scanner на удалённой стороне с запретом зеркал. Чистый Core задаёт исходный направленный объём. Трубные методы и их поведение не меняются. Проверки: все шесть направлений, заблокированная/чужая/за пределом банка, приоритет локального источника, нарушенная связь, запрет цепочки, отсутствие force-load и полный оплаченный ритуал с восстановлением NBT. Полная межчанковая crash-атомарность и исходный FX-пакет этим изменением не закрываются.
